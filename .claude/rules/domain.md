# server/domain

**I/O를 넣지 않는다.** DB·네트워크·파일·시간 전부 금지. 순수 함수와 순수 상태 전이만.
`sqlmodel` · `sqlalchemy` · `httpx` · `open()` 을 import 하면 그 자체로 규칙 위반이다.
영속화가 필요하면 `repository.py` 의 프로토콜로 표현하고 구현은 `server/infra` 가 한다.

**시간은 주입받는다.** `Clock` 프로토콜(`aegis_vision.clock`)을 파라미터로 받는다.
시스템 시계를 직접 읽으면 3초·10초·15초·30초·300초 타이머를 테스트가 순간이동시킬 수
없어 검증 자체가 불가능해진다.

**임계값을 하드코딩하지 않는다.** 정책값은 `Policies`(DB `policies` 테이블)로 받는다.

상태 전이는 기능명세서 §4.2 전이표가 유일한 근거다. 특히:

- `expired` 는 미시정이 아니라 **판정 불가**다. 시정률 분모·분자 모두에서 뺀다.
- 재결합은 이벤트를 살리는 처리이지 **시정을 인정하는 처리가 아니다.** 재결합 후
  위반이 사라져 보여도 해소 타이머는 0부터 다시 채운다.
- 게이팅 보류 구간(`helmet` 미갱신)에서 확정·해소 타이머는 리셋이 아니라 **동결**한다.
- `lost` 상태에서는 쿨다운은 흐르되 재경고를 발동하지 않는다.
