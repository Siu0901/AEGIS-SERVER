# front

**시안보다 명세서가 우선한다.** `docs/AEGIS_front_design.pdf` 는 건설현장 시절에
작성되어 라벨이 낡았다. 레이아웃·정보구조·색상은 따르되 **텍스트와 도메인 용어는
기능명세서 부록 B 대조표를 따른다.**

- 굴착기 → **지게차**(`vehicle`), 굴착 구역 → **지게차 통행로**(`forklift_lane`)
- 중장비 근접 → **지게차 근접**(`proximity`)
- 설정 화면의 「위험요소 등록 · 자연어」 패널은 **미채택 기능이다. 만들지 마라.**

**오버레이는 도착 즉시 그리지 않는다.** 영상(1080p 메인 → 서버 재스트리밍)과 좌표
(640p 서브 → 엣지 → 서버 → WebSocket)는 경로가 달라 지연이 다르다. 즉시 그리면
박스가 사람보다 앞서 움직인다. `overlay` 를 `ts` 키로 지연 버퍼에 담고, 재생 중인
프레임 시각에 맞춰 꺼내 그린다. 정합 오차 목표는 **±100ms**다.

- `overlay_buffer_ms`(기본 300) 만큼 재생을 늦춰 좌표가 먼저 도착하게 한다.
- `overlay_stale_ms`(기본 1000) 초과로 갱신이 없으면 박스를 흐리게 표시한다.
- 박스는 `person` 과 `vehicle` 에만 그린다. **안전모는 별도 박스가 없고** 사람 박스의
  색과 라벨로 표현한다.
- 지표는 항상 병기한다 — `방송 후 시정률 87% (판정 불가 5%)`.

**위반 여부를 클라이언트가 추론하지 않는다.** 서버가 `overlay.objects[]` 에
`violations` · `event_ids` · `alert_state` 를 실어 보낸다. 박스 색은 `violations` 로
정하고, 거리선은 `nearby[].dist_m`(라벨)과 `nearby[].anchor`(반대편 끝점)로 긋는다.
`helmet` 값으로 위반을 유추하지 마라 — `proximity` · `fall` 을 놓친다.

**금지구역 폴리곤은 `overlay` 에 오지 않는다.** 매 프레임 변하지 않으므로
`GET /zones` 로 한 번 조회해 캐시하고, `zone_updated`(§5.4) 를 받아 갱신한다.
캘리브레이션이 바뀌면 지면 좌표계가 통째로 바뀌므로 해당 카메라의 모든 구역에
`upsert` 가 순차로 온다.
