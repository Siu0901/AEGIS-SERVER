# packages/vision

호모그래피·접지점·구역·거리·자세의 **순수 계산만** 둔다. 하드웨어 의존 0이 원칙이다.
`torch` · `tensorrt` · `cv2` · `pycuda` 를 import 하지 않는다. 모델 추론 결과는
숫자로 받아서 계산하고, 추론 자체는 `edge/` 가 한다.

I/O도 없다. 시간이 필요하면 `clock.Clock` 을 주입받는다
(`clock.py` 의 `RealClock` 만 시스템 시계를 읽는 유일한 예외다).

**좌표는 두 종류뿐이다.**

| 표기 | 의미 |
|---|---|
| 접미사 없음 | 정규화 픽셀 좌표 0.0~1.0, 프레임 좌상단 원점 |
| 접미사 `_m` | 지면 실좌표, 단위 미터 |

`_m` 없는 값과 있는 값을 같은 식에 섞으면 안 된다. 변환은 호모그래피를 거친다.

**거리 수치는 항상 호모그래피 값을 쓴다.** 단안 뎁스는 절대거리가 부정확하므로
앞뒤 분리 판별과 깊이 분산 확인에만 쓴다.

**호모그래피 오용 주의**: 사람 마스크 전체를 지면에 투영해 크기를 재지 않는다.
지면 평면 가정 때문에 서 있는 사람의 상반신이 먼 지점으로 투영되어 결과가 역전된다.
호모그래피는 접지점 거리 산출에만 쓴다(기능명세서 FN-DET-10).
