# sim

**서버 입장에서 시뮬레이터는 실물과 구분되지 않아야 한다.** 그래서 실물이 지키는
규칙을 그대로 지킨다.

**엣지는 판단하지 않는다.** 규칙에 걸리면 후보(`candidate`)만 올린다. 확정·경고·
시정판정·재결합은 전부 서버 몫이다. `edge_sim` 안에 "3초 지났으니 확정" 같은 코드가
들어가면 그 순간 서버 상태머신 검증이 무의미해진다. 시나리오 파일 이름이
`no_helmet_resolved` 인 것은 **서버가 그렇게 판정하기를 기대한다**는 뜻이지,
시뮬레이터가 해소를 선언한다는 뜻이 아니다.

**메시지는 반드시 `aegis_contracts` 를 import 해서 만든다.** 여기서 dict를 손으로
조립하거나 스키마를 재정의하지 않는다.

**시간은 `Clock` 에서만 얻는다.** 진입점에서 `RealClock()` 을 만들어 주입한다.

- 시나리오는 `sim/cases/*.yaml` 이며 `ts` 는 적지 않는다(시작 시각 + `at` 으로 주입).
- 시나리오가 적지 않은 필드는 보내지 않는다(`exclude_unset`). `helmet` 생략 규약이
  이 방식으로 표현된다.
- `mcu_sim` 은 경고를 받아 콘솔에 찍을 뿐, 경고 발동 여부를 스스로 정하지 않는다.
