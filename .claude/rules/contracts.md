# packages/contracts

**스키마는 여기에만 정의한다.** 서버·`sim/`·`edge/`·프론트 어디서도 재정의하지 않는다.
같은 메시지를 두 곳에서 정의하면 어느 쪽이 진짜인지 알 수 없게 된다.

**`docs/AEGIS_API명세서.md` 와 1:1이다.** 필드명·타입·필수 여부를 명세서에서 그대로
옮기며 창작하지 않는다. 각 모델 docstring에 출처 절 번호를 적는다(예: `API명세서 §2.1`).

명세서에 없는 필드가 필요해 보이면 **코드를 고치기 전에 사람에게 보고한다.**
명세서가 SSOT이므로 코드가 앞서 나가면 안 된다.

- `extra="forbid"` 는 의도적이다. 명세서에 없는 필드가 실려 오면 계약 위반이므로
  조용히 통과시키지 않는다.
- 감지 클래스는 `person` · `vehicle` 2종 고정이다. 런타임에 추가하는 API는 없다.
- `helmet` 은 `on` / `off` 두 값뿐이다. `unknown` 을 추가하지 마라. 판정 불가는
  **필드 생략**으로 표현한다.
- 명세서 예시 JSON은 `tests/test_spec_examples.py` 에 그대로 들어 있다. 모델을 바꿨는데
  이 테스트가 깨지면 **모델이 틀린 것**이다.
