# edge

실물 엣지 러너. 영상에서 직접 후보를 만들어 `/ws/edge` 로 올린다.

**개발 중에는 `sim/edge_sim` 이 이 자리를 대신한다.** 시뮬레이터는 M9 에서 버리는 것이
아니라 **서버의 테스트 하네스로 남는다** — 재결합·판정 불가·게이팅 동결 같은 전이를
사람과 실물 장비 없이 만들 수 있는 유일한 수단이고, CI 가 그것에 의존한다.

```
운영  :  실물 엣지(여기)  ──▶ /ws/edge ──▶ 서버
테스트:  sim/edge_sim     ──▶ /ws/edge ──▶ 서버
```

## 실행

영상은 **RTSP 로만** 받는다. 파일 경로를 직접 열지 않으므로 카메라가 먼저 떠 있어야 한다.

```
uv run tasks.py cams --source media/lego_sample_1.mp4   # 가짜 카메라
uv run tasks.py edge --cam 1                            # 엣지 러너
```

호모그래피가 없으면 좌표를 낼 수 없어 프레임을 건너뛴다. 설정 화면에서 4점을 먼저
찍어야 한다(FN-CFG-01).

## 노트북(CPU)과 젯슨의 차이는 `runtime.backend` 하나다

| | 노트북 | 젯슨 Orin Nano |
|---|---|---|
| `runtime.backend` | `onnx` (onnxruntime · CPU) | `tensorrt` |
| 모델 파일 | `models/weights/*.onnx` | `models/engines/*.engine` |
| `decode.backend` | `cpu` | `nvdec` |

`.pt` → `.onnx` 변환은 `scripts/export_onnx.py` 가 한다(일회성). 그쪽이 쓰는
torch·ultralytics 는 루트의 `export` 의존성 그룹에 있고 **엣지 런타임에는 없다** —
젯슨에 torch 를 올릴 이유가 없다.

TensorRT 엔진은 **빌드한 GPU 에 종속되므로 젯슨에서 직접 빌드한다**(`models/README.md`).

## M9 에서 손봐야 할 것 — 숨기지 않는다

- **추적기에 칼만 필터가 없다.** `track.py` 는 ByteTrack 의 핵심(높은 신뢰도로 먼저
  잇고, 남은 트랙을 낮은 신뢰도로 한 번 더)은 그대로 구현하지만 위치 예측은 등속
  근사다. 노트북 실측 처리율이 2~3fps 라 프레임 간격이 예측 정밀도보다 지배적이었다.
  8fps 이상이 나오는 젯슨에서는 ultralytics 의 ByteTrack 구현으로 교체하는 것이 맞다.
- **`track.buffer_frames` 는 프레임 수다.** 처리율이 바뀌면 같은 시간이 되도록 다시
  잡아야 한다(노트북 2~3fps 에서 8프레임 ≈ 3초).
- **시계 오차를 측정하지 않는다.** `heartbeat.clock.synced` 를 `false` 로 보낸다 —
  측정하지 않은 값을 0으로 보고하면 동기화된 적 없는 엣지가 완벽한 것으로 보인다(§2.4).
- **`footpoint` 절은 정책 키가 아니다.** 명세서 §4.5 목록에 없어서 `config.yaml` 에
  뒀다. 승격이 필요하다고 판단되면 코드보다 명세서를 먼저 고친다(절대규칙 8).

## 주의할 것

- **모델 입력은 정사각이 아니다.** `imgsz: [384, 640]` rect letterbox 다. 정사각(640×640)
  으로 두면 위아래 패딩까지 연산해 픽셀 수가 약 1.67배가 된다(기능명세서 §5).
- **서브 스트림은 640×360(16:9)** 이며 메인(1920×1080)과 화면비가 같아야 한다. 다르면
  정규화 좌표가 눌려 대시보드 오버레이가 어긋난다(API명세서 §1.2). 로더가 막는다.
- **마스크는 밖으로 나가지 않는다.** 계약에 마스크 필드가 없다. 윤곽은 접지점·자세·
  최근접 거리를 구하는 데만 쓰이고, 화면에 그려지는 것은 박스와 거리선이다.
- **제로샷을 쓰지 않는다.** 가중치가 YOLOE 계열이어도 이미 학습된 클래스를 쓰므로
  `set_classes()` 를 부르지 않는다. 학습 라벨 → 계약 클래스 매핑은 `config.yaml` 의
  `classes:` 표가 하고, 표에 없는 클래스는 버린다(절대규칙 11).
- **YAML 의 `on`/`off` 는 불리언이다.** 안전모 라벨은 반드시 따옴표로 감싼다.
- 판정 임계값은 여기가 아니라 서버 DB `policies` 에 있다. 현장에서 화면으로 조정하는
  값이기 때문이다. 엣지는 `GET /policies` 로 받아오며 30초마다 다시 읽는다.
