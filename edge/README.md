# edge

실물 Jetson Orin Nano 러너. **M9에서 작업하며 그 전까지 비워둔다.** 개발 중에는 `sim/edge_sim` 이 이 자리를 대신한다.

`config.yaml` 은 지금부터 유지한다 — 모델 경로·엔진·입력 형태를 코드에 하드코딩하지 않기 위한 자리다(CLAUDE.md 절대규칙 6).
판정 임계값은 여기가 아니라 서버 DB `policies` 테이블에 있다. 현장에서 화면으로 조정하는 값이기 때문이다.

주의할 두 가지:

- **모델 입력은 정사각이 아니다.** `imgsz: [384, 640]` rect letterbox 다. 정사각(640×640)으로 두면 위아래 패딩까지 연산해 픽셀 수가 약 40% 늘어난다(기능명세서 §5).
- **서브 스트림은 640×360(16:9)** 이며 메인(1920×1080)과 화면비가 같아야 한다. 다르면 정규화 좌표가 눌려 대시보드 오버레이가 어긋난다(API명세서 §1.2).
